学习

  1. echo
    输出

  2. 变量
    $name=’微博’;//字符串类型
    $age=18;//int类型
    $boolValue=true;//布尔类型
    $arrayValue=array(‘1’,’2’,3,true,1.11);//数组类型

  3. 常量
    常量
    define(‘name’,’fly’);
    echo name ;//;fly

  4. var_dump()
    var_dump() 函数返回变量的数据类型和值：
    var_dump(‘aaa’);
    1
    2

  5. php类型比较
    使用两个等号 == 比较，只比较值，不比较类型
    用三个等号 === 比较，除了比较值，也比较类型。

  6. 计算

$a=10;$b=3;
加法：+ $a+$b 结果是13
减法：- $a-$b 结果是7
乘法：* $a*$b 结果是30
除法：/ $a/$b 结果是3.33333
取余：% $a%$b 结果是1
取反：- -$a 结果是-10
并值：. $a.$b 结果是103

  1. if…else
    if(1==2){
    echo ‘1’;
    }else{
    echo ‘2’;
    }
    //最后输出2

  2. if…elseif…else
    $a=3;
    if($a==1){
    echo ‘1’;
    }elseif ($a==2){
    echo ‘2’;
    }else{
    echo ‘3’;
    }
    //最后输出3

  3. switch
    $a=3;
    switch ($a){
    case 1:
    echo ‘1’;
    break;
    case 2:
    echo ‘2’;
    break;
    case 3:
    echo ‘3’;
    break;
    default:
    echo ‘default’;

}
//最后输出3

14. 数组排序
//sort() - 对数组进行升序排列
//rsort() - 对数组进行降序排列
//asort() - 根据关联数组的值，对数组进行升序排列
//arsort() - 根据关联数组的值，对数组进行降序排列
//ksort() - 根据关联数组的键，对数组进行升序排列
//krsort() - 根据关联数组的键，对数组进行降序排列

//sort() - 对数组进行升序排列
//rsort() - 对数组进行降序排列
$agesArray = array(30,35,20,14,19);
sort($agesArray);
echo ‘sort() ：对数组升序
‘;
for ($x=0;$x<count($agesArray);$x++){
echo ‘第’.$x.’个元素值：’.$agesArray[$x].’;’;
}
sort() ：对数组升序
第0个元素值：14;第1个元素值：19;第2个元素值：20;第3个元素值：30;第4个元素值：35;

echo ‘
sort() ：对数组降序
‘;
rsort($agesArray);
for ($x=0;$x<count($agesArray);$x++){
echo ‘第’.$x.’个元素值：’.$agesArray[$x].’;’;
}
rsort() ：对数组降序
第0个元素值：35;第1个元素值：30;第2个元素值：20;第3个元素值：19;第4个元素值：14;
//asort() - 根据关联数组的值，对数组进行升序排列
//arsort() - 根据关联数组的值，对数组进行降序排列
$students=array(0=>200,1=>80,2=>50);

asort($students);
echo ‘

asort 根据关联数组的值，对数组进行升序排列
