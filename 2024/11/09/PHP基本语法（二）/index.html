PHP基本语法（二）

发表于2024-11-09|更新于2024-11-16
|浏览量:

循环结构语句：

1.while循环语句
概念：是根据循环条件来判断是否重复执行这一段代码的
2.do...while循环语句
概念：和while相似，唯一区别是：while是先判断后执行循环体，而do...while会先执行一次循环体在判断
3.for循环语句

概念： for循环语句是最常用的循环语句，它适合循环次数已知的情况

跳转语句  

    1.break
    可应用在Switch和循环语句中，其作用是终止当前语句的执行，跳出本次循环
    2.continue
    与break语句的区别在于，前者用于结束本次循环执行，开始下一轮循环的操作，后者是终止当前循环，跳出循环体。

冒泡排序
冒泡排序是一种简单的排序算法，它重复地遍历要排序的数列，一次比较两个元素，如果它们的顺序错误就把它们交换过来。遍历数列的工作是重复地进行直到没有再需要交换，也就是说该数列已经排序完成。
以下是使用PHP实现冒泡排序的示例代码：
function bubbleSort(array $arr) {
$size = count($arr);
for ($i = 0;$i < $size - 1;$i++) {
for ($j = 0;$j < $size -$i - 1; $j++) {
if ($arr[$j] > $arr[$j + 1]) {
// 交换两个元素的位置
$temp =$arr[$j];
$arr[$j] = $arr[$j + 1];
$arr[$j + 1] = $temp;
}
}
}
return $arr;
}

// 测试冒泡排序函数
$array = [64, 34, 25, 12, 22, 11, 90];$sortedArray = bubbleSort($array);
print_r($sortedArray);
在这个例子中，bubbleSort 函数接受一个数组作为参数，并返回排序后的数组。内部的两个循环负责执行排序逻辑。外层循环控制排序需要进行多少轮，内层循环负责在每一轮中执行实际的比较和交换操作。

函数
在PHP中，函数是一段执行特定任务的代码块。您可以通过定义函数来封装可重复使用的代码。下面是关于PHP函数的一些基本概念和用法：
定义函数
在PHP中，您可以使用function关键字来定义一个函数。以下是定义函数的基本语法：
function functionName($parameter1, $parameter2, …) {
// 函数体 - 要执行的代码
return $result; // 返回值（可选）
}
调用函数
定义函数后，您可以通过其名称来调用它：
$result = functionName($argument1, $argument2, …);
函数示例
以下是一个简单的PHP函数示例，该函数接受两个参数并返回它们的和：
function add($a, $b) {
return $a + $b;
}
echo add(5, 3); // 输出 8
函数参数
必需参数：在调用函数时必须提供的参数。
默认参数：如果在调用函数时没有为参数提供值，则使用默认值。
可变数量参数：使用…语法可以接受可变数量的参数。
返回值
函数可以使用return语句返回一个值。如果函数没有return语句，则默认返回null。
作用域
在PHP中，变量有局部作用域和全局作用域。函数内部定义的变量是局部变量，只能在该函数内部访问。
全局变量
如果您想在函数内部访问全局变量，可以使用global关键字或者$GLOBALS超全局数组。
$number = 1;
function increment() {
global $number;
$number++;
}
increment();
echo $number; // 输出 2
或者使用$GLOBALS：
$number = 1;
function increment() {
$GLOBALS[‘number’]++;
}
increment();
echo $number; // 输出 2
匿名函数
PHP也支持匿名函数（也称为闭包），它允许您创建没有名称的函数。
$greet = function($name) {
printf(“Hello %s\r\n”, $name);
};
$greet(‘World’); // 输出 Hello World
面向对象
面向对象编程（Object-Oriented Programming，简称OOP）是一种编程范式，它使用对象和类来设计软件。在面向对象编程中，对象是具有属性（数据）和方法（行为）的实体。以下是面向对象编程的一些核心概念：
类（Class）
类是创建对象的蓝图或模板。它定义了对象的属性（变量）和方法（函数）。
定义一个类
在PHP中，使用class关键字来定义一个类：
class MyClass {
// 类的属性
public $property = “I am a property”;
// 类的方法
public function myMethod() {
echo “I am a method”;
}
}
对象（Object）
对象是类的实例。使用new关键字来创建一个对象。
创建对象
$obj = new MyClass();
属性（Property）
属性是对象中存储数据的变量。
访问属性
echo $obj->property; // 输出 “I am a property”
方法（Method）
方法是对象中定义的函数。
调用方法
$obj->myMethod(); // 输出 “I am a method”
封装（Encapsulation）
封装是隐藏对象的实现细节，仅暴露出必要的方法和属性。
访问修饰符
public：可以在任何地方访问。
private：只能在类的内部访问。
protected：可以在类内部和子类中访问。
继承（Inheritance）
继承允许一个类继承另一个类的属性和方法。
示例
class ChildClass extends MyClass {
// ChildClass 继承 MyClass 的属性和方法
}
多态（Polymorphism）
多态允许不同类的对象通过共同的接口或基类调用相同的方法，但表现出不同的行为。
示例
class Animal {
public function makeSound() {
echo “Some sound”;
}
}
class Dog extends Animal {
public function makeSound() {
echo “Woof!”;
}
}
class Cat extends Animal {
public function makeSound() {
echo “Meow!”;
}
}
$dog = new Dog();
$cat = new Cat();
$dog->makeSound(); // 输出 “Woof!”
$cat->makeSound(); // 输出 “Meow!”
抽象类（Abstract Class）
抽象类不能被实例化，它主要用于定义接口和基类。
示例
abstract class AbstractClass {
abstract protected function getValue();
abstract protected function prefixValue($prefix);
public function printOut() {
print $this->getValue() . “\n”;
}
}
class ConcreteClass1 extends AbstractClass {
protected function getValue() {
return “ConcreteClass1”;
}
public function prefixValue($prefix) {
return “{$prefix}{$this->getValue()}”;
}
}
接口（Interface）
接口定义了类必须实现的方法，但不包含实现细节。
示例
interface AnimalInterface {
public function makeSound();
}
class Dog implements AnimalInterface {
public function makeSound() {
echo “Woof!”;
}
}
面向对象编程提供了许多优势，如代码的可重用性、模块化、和维护性。这些概念在PHP和其他面向对象的编程语言中都非常重要。
