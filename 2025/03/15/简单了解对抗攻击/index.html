简单了解对抗攻击

发表于2025-03-15|更新于2025-03-15
|浏览量:

一、对抗攻击基础概念

  1. 定义与分类

(1)知识级别:白盒攻击:对抗样本生成过程完全可见，攻击者完全掌握模型结构、参数及训练数据，攻击者可以直接修改模型参数、训练数据、模型结构等，通过对抗样本的特征或输出进行推理，获取模型的内部信息。黑盒攻击:对抗样本生成过程不可见，攻击者只能通过模型的API接口获取模型的输出，无法直接修改模型参数、训练数据、模型结构等。

(2)攻击目标:目标攻击:攻击目标是模型的预测结果，如对图像进行分类，攻击者希望模型将目标类别错误预测为其他类别。非目标攻击:攻击目标不是模型的预测结果，如对图像进行分类，攻击者希望模型将任意类别错误预测为目标类别。

(3)扰动可见性:可感知攻击:攻击者可以观察到扰动的效果，如对图像进行分类，攻击者可以看到扰动后的图像，可以判断扰动的幅度。隐形攻击:攻击者无法观察到扰动的效果，如对图像进行分类，攻击者只能看到扰动后的图像的类别标签，无法判断扰动的幅度。

  1. 数学形式化

对抗样本生成可表示为约束优化问题：

fθ：目标模型
δ：对抗扰动
ϵ：扰动上限
p：范数类型（常用L∞/L2）

二、经典攻击算法

  1. FGSM（Fast Gradient Sign Method）

原理：沿梯度上升方向添加扰动

符号 解释 单位/取值范围 示例
δ 对抗扰动 与输入图像同维度 微小像素变化
ϵ 扰动幅度的上限 正实数（通常 0.01∼0.10.01∼0.1） ϵ=0.03
∇x 损失函数对输入 xx 的梯度 梯度张量 梯度方向指示扰动方向
L 损失函数（如交叉熵损失） 标量值 L=−log⁡fy(x)
f(x) 模型的预测输出 类别概率向量 输出 [0.1,0.9]
y 输入的真实标签 整数（类别索引） y=1（猫）

*符号函数sign：返回输入值的符号（正负号），忽略具体数值大小。

特点：

单步攻击，计算高效

适合生成隐形对抗样本

  1. PGD（Projected Gradient Descent）

原理：迭代式FGSM，每次迭代后投影到约束空间

符号 解释 单位/取值范围 示例
x**t 第 tt 次迭代的对抗样本 与输入图像同维度 迭代优化的中间结果
Projϵ 将扰动投影到 ϵϵ-邻域内 约束函数 限制扰动幅度
α 单次迭代的步长 正实数（通常 α=ϵ/10） α=0.003
t 当前迭代次数 整数 t=0,1,…,T−1

特点：

攻击效果强于FGSM

常用于对抗训练

  1. C&W攻击（Carlini-Wagner）

原理：优化目标函数，最小化扰动幅度

符号 解释 单位/取值范围 示例
∥δ∥2 扰动的 L2 范数 正实数 ∥δ∥2=1.5
c 平衡扰动大小与攻击成功的权重 正实数（需调参） c=10
ftarget 目标类别的预测概率 [0,1] ftarget=0.9
fi 第 ii 个类别的预测概率 [0,1] f1=0.1,f2=0.8

特点：

目前最强的L2攻击方法

可绕过大多数防御机制

三、防御技术全景

  1. 主动防御

(1)对抗训练:通过对抗样本训练模型在训练数据中加入对抗样本提升鲁棒性，但可能降低正常准确率

(2)输入预处理:对输入数据进行预处理，如归一化、裁剪、旋转、缩放等，增强模型鲁棒性,如图像增强、文本增强,但可能降低模型性能

(3)梯度掩码:隐藏模型的梯度信息,增加攻击难度,可能被自适应攻击破解

  1. 被动检测

异常检测:统计输入数据的特征分布，识别异常样本

模型验证:使用辅助模型检测对抗样本

  1. 攻击效果评估指标

def evaluate_attack(adv_acc, orig_acc, psnr):
“””综合评估攻击效果”””
success_rate = 1 - adv_acc / orig_acc
stealth_score = psnr / 40 # 假设PSNR>40为不可感知
return 0.7success_rate + 0.3stealth_score

  1. 参数调优策略

学习率:初期使用较大值（如0.01），后期逐步衰减至较小值,平衡收敛速度与稳定性
迭代次数:根据PSNR曲线动态调整（当PSNR变化<0.1dB时停止迭代）,避免过优化
扰动约束:从宽松约束开始（如L∞=0.1），逐步收紧,寻找最小有效扰动

五、前沿研究方向

  1. 物理世界攻击：让数字攻击照进现实

核心挑战：
数字世界的攻击像「PS修图」，而物理攻击是「在真实物品上做手脚」。需要克服三大现实限制：
• 视角变化：攻击贴纸在不同角度拍摄下可能失效
• 光照干扰：强光/阴影会改变攻击图案的视觉效果
• 材质限制：打印分辨率、反光特性影响攻击效果

经典案例：
2018年MIT团队在停车标志上贴黑白贴纸，成功让自动驾驶系统识别为「限速45mph」。
关键技术：
• 使用EOT（Expectation Over Transformation）算法，模拟不同拍摄角度
• 在3D建模软件中预渲染攻击效果
• 选择高对比度图案抵抗光线变化

实验复现步骤：
(1) 用Blender建立交通标志3D模型
(2) 生成对抗贴纸图案
(3) 3D打印贴纸并实地测试
(4) 用手机多角度拍摄验证攻击效果

最新进展：
• 对抗服装：穿特殊图案T恤欺骗人脸识别系统
• 声波攻击：超声波干扰让手机麦克风接收错误指令
• 激光干扰：用激光笔照射摄像头导致目标检测失效

  1. 语义攻击：篡改图像的故事线

与传统攻击对比：

攻击类型 修改方式 人类感知 示例
传统攻击 像素级微小扰动 不可见 噪点般的细微变化
语义攻击 增删/修改物体 可见但合理 给卡车添加特殊纹理

技术实现路径：
A[选择目标物体] –> B(使用GAN生成合理变体)
B –> C{是否符合语义}
C –>|Yes| D[生成对抗样本]
C –>|No| B
D –> E[测试模型欺骗率]

典型应用场景：
• 电商攻防：在商品图上添加隐藏图案，绕过盗图检测
• 社交网络：修改图片中文字内容，误导内容审核AI
• 军事伪装：给装备涂装特殊图案，干扰卫星识别

3. 自适应防御：打造AI的「免疫系统」

防御机制对比：

防御类型 原理 缺点 代表方法
静态防御 固定预处理流程 容易被针对性绕过 JPEG压缩、随机裁剪
自适应防御 动态调整防御策略 计算开销较大 随机化模型

动态防御框架：
class AdaptiveDefense(nn.Module):
def init(self, base_model):
super().init()
self.models = [base_model(), base_model(with_dropout=True), base_model(pruned=True)]

def forward(self, x):
    model = random.choice(self.models)  # 随机选择模型变体
    return model(x)

核心思想：将对抗训练转化为min-max优化问题

符号 解释 单位/取值范围 示例
θ 模型参数 权重矩阵/向量 神经网络权重
E 期望（平均）操作符 数学期望 所有训练样本的平均
Δ 允许的扰动集合 约束空间 Δ={δ∣∥δ∥∞≤ϵ}
